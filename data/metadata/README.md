# Metadata and accessions

- `mag_qc.csv`: CheckM completeness, contamination and lineage for 302 MAGs.
- `mag_metadata_120.csv`: verified identifiers and CheckM values for the 120 selected MAGs.
- `sample_metadata.csv`: metadata for the 14 samples used in the archived MAG coverage matrix.
- `Beluga_MIMARKS_MIMS_MIMAGS_03.09.2026.xlsx`: MIMARKS, MIMS and MIMAG metadata workbook.
- `sra_amplicon_accessions.tsv`: accession metadata for 80 **amplicon** runs.

The 120 MAG assemblies were submitted under NCBI genome submission `SUB16390494` associated with BioProject `PRJNA1506697`. Validation and genome accession assignment remain pending according to the latest available submission status.
